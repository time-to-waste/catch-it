About This Website

Welcome to Catch the Dot! This is a small browser game designed to help players practice their mouse accuracy and reaction speed.

The goal is simple: click as many targets as possible before the 20-second timer ends. Every few points, the target becomes smaller, making the challenge harder.

Your best score is automatically saved in your browser, so you can keep trying to beat your personal record.

This website was built using HTML, CSS and JavaScript. It is hosted using GitHub Pages.
